# Assets

Ce dossier contient les ressources visuelles de l'application.

## Images requises

- `icon.png` - Icône de l'application (1024x1024px)
- `splash.png` - Écran de démarrage (1284x2778px)
- `adaptive-icon.png` - Icône adaptative Android (1024x1024px)

## Génération automatique

Pour l'instant, l'application peut fonctionner sans ces images car elles ne sont chargées qu'au build final. En développement avec Expo, des placeholders sont utilisés automatiquement.

Pour générer ces images plus tard, vous pouvez utiliser des outils comme:
- Figma
- Canva
- Adobe Illustrator
- Ou tout simplement des fichiers PNG avec les bonnes dimensions
